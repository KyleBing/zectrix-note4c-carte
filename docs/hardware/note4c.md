| 尺寸 | 4.2 英寸 |

| 颜色 | 黑、白、红、黄（BWRY） |

开发注意：

- 刷新过程中的闪烁、短暂反色、色粉移动属正常现象
- 断电后画面可保持；有画面 ≠ 设备仍在运行
- 厂商官网公开托管的 SSD2683 数据手册目前未在 Wiki 提供；开发以原理图映射、面板配置、公开驱动源码为准

### 4.1 bpp 是什么

**bpp = bits per pixel（每像素比特数）**，表示 framebuffer 里用多少 bit 描述一个像素的颜色。

| bpp | 含义 | 能表示的状态数 | 本硬件上的典型用途 |
| --- | --- | --- | --- |
| 1 bpp | 每像素 1 bit | \(2^1 = 2\) | 黑白 NOTE4：黑 / 白 |
| 2 bpp | 每像素 2 bit | \(2^2 = 4\) | **NOTE4C**：黑 / 白 / 黄 / 红 |
| 4 bpp | 每像素 4 bit | \(2^4 = 16\) | 黑白 NOTE4 灰阶相册等（与 NOTE4C 无关） |

NOTE4C 参考固件分支名里的 **`2bp` / `2bpp`** 即指这种四色像素格式。

本仓库 / 参考仓常用编码（与 LazyYoun rawdraw 一致）：

| 2-bit 值 | 颜色 |
| --- | --- |
| `00` (0) | 黑 Black |
| `01` (1) | 白 White |
| `10` (2) | 黄 Yellow |
| `11` (3) | 红 Red |

整屏缓冲大小：

\[
400 \times 300 \times 2\ \text{bit} = 240{,}000\ \text{bit} = 30{,}000\ \text{byte}
\]

一行 400 像素 → \(400 \times 2 / 8 = 100\) 字节。一个字节装 4 个像素（高位像素在前）：`(c3<<6)|(c2<<4)|(c1<<2)|c0`。

仓库里分支/文件名常见的 **`1bpp`**、**`2bpp`/`2bp`**、**`4bpp`/`4bp`** 都是在说「每像素几 bit」，不是屏幕尺寸。

### 4.2 四色成像原理（BWRY）

电子墨水不是发光屏，也不是液晶滤色片叠光，而是 **电泳色粉**在电场里换位：

1. 每个像素对应微杯 / 微胶囊，内有透明液 + **多种带电色粉**。
2. 四色（BWRY）面板通常配置黑、白、红、黄等不同电荷/阈值的粒子体系。
3. 控制器按面板 OTP 里的 **波形表（LUT）** 输出多段电压；目标颜色的粒子被推到观察面，其它粒子沉下或侧移。
4. **一个像素稳态下通常只看到一种主色**（2bpp 四选一）。多种粒子同时挤在观察面多半是驱动不完整（发灰、残影），不是正常「多色叠加」。
5. **一块区域里的很多像素**可以各自显示不同颜色，所以整页可以同时有黑白红黄。
6. 断电后粒子基本停住 → 画面保持、静态几乎不耗电；有画面 ≠ 芯片仍在跑。

和二色屏的差别：

| | 二色（如 NOTE4 黑白） | 四色 NOTE4C |
| --- | --- | --- |
| 粒子体系 | 主要黑 / 白 | 黑 / 白 / 红 / 黄 |
| 像素数据 | 常 1 bpp（或灰阶 4 bpp） | **2 bpp** |
| 波形 | 较短，可做差动 / 窗口局部 | 更长、多段；公开资料为 **整屏刷新** |
| 「画面只用黑白」 | — | **不会自动变快**：仍走四色全刷波形，红黄粒子也要被安置 |

驱动在做的事：写 2bpp 帧缓冲 → 发 SPI 命令触发全刷波形 → 粒子重排完成成像。自写驱动无法发明面板 OTP 里没有的「小窗单色快刷」能力。

## 6. 电源与复位

| 项目 | 说明 |
| --- | --- |
| 电池 | 2,000+ mAh 可充电电池 |
| 电源保持 | **GPIO17** 控制主板电源锁存；电池运行固件启动后需维持所需锁存状态 |
| 电源键 | **GPIO18** 兼下键 / 电源键；开/关机与长按行为由固件定义 |
| 硬件 RESET | 左侧针孔 → EN / RST；短按复位主控，不擦固件 |

### 6.1 手动进入下载模式

多数电脑可直接识别。若刷机工具 / `esptool` 找不到设备：

1. USB Type-C 数据线保持连接（需 **数据传输线**，充电-only 无效）
2. 按住正面圆形 **BOOT**（GPIO0）
3. 保持 BOOT，短按左侧 **RESET** 针孔一次
4. 松开 BOOT
5. 重新选择新出现的 ESP32-S3 串口

## 11. 开发相关硬件约束

1. **仅 2.4 GHz Wi-Fi**（无 5 GHz-only 网络）
2. **合并固件镜像写入地址 `0x0`**（不要写到 `0x20000`）
3. **禁止向 NOTE4C 刷黑白 NOTE4 固件**
4. 改第三方固件 / 分区表前先备份完整 16 MB Flash
5. 电池模式必须正确驱动 **GPIO17 电源保持**
6. 四色全刷慢，UI 设计应避免高频整屏刷新
