# App 功能说明

> 桌面 App 与设备 **Web 配置站** 各做什么。  
> 总览 / 按键 / 刷写见 [固件功能说明](/features/)；运行时细节见 [行为机制](/features/behavior)。  
> 版本：`{{DOC_VERSION}}`

上下短按在**已启用**的 App 间循环（顺序：**待办 → 日历 → 天气 → 相册 → 状态 → 象棋 → 名言**）。顶栏色点表示当前位置（只开一个 App 时不画色点）。**BOOT 从不切 App**，只做当前页内动作。不用的 App 可在 Web `/settings` 关掉。

## 待办（TODO）

待办正文可以是 **Portal 日记**，也可以是设备 **本机正文**（LittleFS），在 Web `/todo` 切换。

| 项 | 说明 |
| --- | --- |
| 网络来源 | `GET /portal/diary/detail?diaryId=`（需 `/auth` 登录并选 Diary ID） |
| 本机来源 | 在 `/todo` 用日记原文格式直接编辑，存 `/todo/local.txt`；不依赖联网 |
| 正文格式 | 行首 `- ` 未完成、`= ` 已完成；可选 `#备注`（备注用红色画在条目下） |
| 排序 | 未完成在前，已完成在后 |
| 屏上内容 | 顶栏 TODO + 电池；勾选框列表；失败时「错误详情」 |
| BOOT | 网络模式：重新拉取并全刷；本机模式：重读本机正文并全刷 |
| 依赖 | 网络模式需 WiFi + Portal Token；本机模式可离线 |

Web `/todo` 可切换数据源、编辑本机正文，并预览勾选列表。

## 日历（CALENDAR）

本机 **PCF8563** 月历，偏「一眼看今天」。

| 项 | 说明 |
| --- | --- |
| 画面 | 顶栏年月；格内**大字公历** + **小字农历**；**今天**红底白字 |
| 周起始 | Web 设置可配周一 / 周日为第一列（默认周一） |
| 校时 | 复位后联网 NTP 校一次；平时按周期（默认约 30 天，可配）；也可在 Web 手动写 RTC / 时区 |
| 醒着 | 停在日历 App 时，本地日期跨天会自动重绘 |
| 关机 | 前台是日历 → 定时深睡，约**次日 0:00** RTC 唤醒刷新年月「今天」再睡 |
| BOOT | 立刻重绘（必要时顺带校时） |

不依赖 Portal；有 WiFi 时校时更准，纯离线也能用手设时间跑月历。

## 天气（WEATHER）

经 Portal 代理访问和风；**设备不存和风 Key**。需：天气启用 + 已登录 + 已选城市 LocationID。

| 模式 | 屏上大致内容 | BOOT |
| --- | --- | --- |
| **NOW** | 大图标 + 天气名 / 气温 / 湿度；风向与空气质量；下方未来约 6 小时气温柱 | 切到 7D |
| **7D** | 未来 7 天高低气温柱（按气温区间四色/抖动填色）；日期与周几 | 切回 NOW |

| 项 | 说明 |
| --- | --- |
| 配置 | Web `/weather`：开/关、城市搜索选点；**日天气 / 周天气**各自定时开关与间隔 |
| 醒着定时 | 停在 NOW 或 7D 时，按对应档间隔自动拉数全刷 |
| 关机定时 | 前台是天气且当前档定时开 → RTC 深睡到点醒刷再睡 |
| 失败 | 屏上错误详情 + `/errors` 日志；未配齐时提示去 `/auth`、`/weather` |

顶栏黄标标出当前是 NOW 还是 7D。柱色、风向图标等版面细节见 [行为机制 · 天气](/features/behavior#63-天气)。

## 相册（ALBUM）

墨水屏**四色照片**轮播。设备不解 JPG：在 Web `/album` 里裁切、色阶、抖动成 400×300 的 `.2bp`，再上传到 LittleFS。

| 项 | 说明 |
| --- | --- |
| 设备端 | 按「展示中」列表全屏显示；可选叠 ALBUM 顶栏与 `当前/总数` |
| BOOT | 下一张（跳过「取消展示」的） |
| 定时翻页 | Web 可开；醒着停在相册到期翻页；关机前台为相册且开关开 → RTC 到点翻页再睡 |
| 展示开关 | 「取消展示」只藏图，文件仍在，不关相册 App |
| 批量 | 导入 / 导出 ZIP、勾选删除、全选展示等 |
| 容量 | 受 LittleFS 分区限制（约数 MB 级，张数随文件变） |

电脑上也可先跑 `python3 tools/web_preview.py` 模拟整站配置页（不必刷机）；相册完整编辑用 `python3 tools/album_preview.py`。

## 状态（STATUS）

本机资源与定时开关一览，不依赖联网。

| 项 | 说明 |
| --- | --- |
| 内容 | 固件版本 / 编译时间、RTC 时间、Heap / PSRAM、LittleFS、电池、WiFi |
| 定时 | 天气 / 相册 / 象棋 / 名言定时是否开启及间隔；日历跨天；空闲关机 |

## 象棋（CHESS）

国际象棋**练习展示**：8×8 棋盘 + 两侧已吃子 icon；无底栏、无顶栏 App 色点。

| 项 | 说明 |
| --- | --- |
| 画面 | 黄白格；像素棋子（黑实心 / 白黄填）；左右「白方吃 / 黑方吃」 |
| 文案 | 局面名、行棋方、目标（几步杀 / 守和 / 升变等） |
| 等级 | Web `/chess` 可多选：开局 / 战术 / 中局 / 残局；只展示勾选等级 |
| 顺序 | 顺序翻局或乱序；BOOT / 定时翻下一局 |
| 定时 | 可开间隔翻局；醒着停在象棋到期翻；关机前台为象棋且开关开 → RTC 到点翻再睡 |
| BOOT | 下一局 |

## 名言（QUOTE）

墨水屏展示**名言 / 诗词**；列表存 LittleFS，首次空列表写入内置种子（可升级合并）。

| 项 | 说明 |
| --- | --- |
| 画面 | 正文居中（可 1×/2× 自适应）；诗词按换行分句居中；作者右下带短横线 |
| 容量 | 最多 64 条；正文约 240 字、作者约 48 字 |
| 顺序 | 顺序或乱序翻条 |
| 定时 | 可开间隔翻条；醒着 / 关机 RTC 与象棋、相册同理 |
| BOOT | 下一条 |
| Web | `/quote`：播放与定时设置；**左列表点选、右栏编辑 / 删除 / 新增**；可恢复内置列表 |

不依赖联网。诗词在正文里用换行分句即可。

## Web 配置

长按 **UP ~1.5s** 启动配置站（不是桌面 App 之一，但是配置它们的入口）：

1. 优先用已存 WiFi 开 **同网段站点**（墨水屏显示本机 IP）  
2. 失败则开 **AP**：SSID `Note4C-Carte`，密码 `12345678`，浏览器打开 `http://192.168.4.1`  
3. 已在 Web 时再长按 UP：**AP ↔ 同 WiFi 站点** 切换  

墨水屏配置页会画模式图标、热点名/密码或访问地址，并黄底提示「当前模式不会自动关机」。**BOOT** 退出 Web 并刷回当前可用 App。保存配置一般不自动退出。

电脑上可先跑 `python3 tools/web_preview.py` 用假数据看整站布局（移动端用浏览器 DevTools）；相册完整编辑仍用 `album_preview.py`。

| 路径 | 做什么 |
| --- | --- |
| `/` | 状态总览：联网、Portal、各 App 摘要、存储 / 内存 / 固件 / 电池；错误条数入口 |
| `/settings` | **App 开关**；空闲自动关机；日历周起始 / 时区 / NTP / 手动对时 |
| `/wifi` | 最多 **5** 组 SSID；选 Active；连接顺序 Active → 其余 |
| `/auth` | Portal Base URL（默认 `https://kylebing.cn/portal`）、邮箱登录、选 / 填 Diary ID |
| `/todo` | 切换网络 / 本机数据源；编辑本机正文；预览列表 |
| `/weather` | 天气启用、城市搜索、日/周天气各自定时刷新 |
| `/album` | 选图 → 裁切 / 色阶 / 抖动 → 上传；列表管理与定时翻页 |
| `/chess` | 翻局顺序、练习等级、定时翻局 |
| `/quote` | 名言设置与列表（左列表 / 右编辑） |
| `/schedule` | **定时刷新总览**（天气 / 相册 / 象棋 / 名言）；**静默时段**；**每日 App 时间表** |
| `/errors` | 最近错误事件（最多 40 条），可清空 |
| `/help` | 按键与 LED 图案说明（旧 `/led` 跳到这里） |

### 日程页（`/schedule`）

| 块 | 说明 |
| --- | --- |
| 定时刷新 | 一页改日天气 / 周天气 / 相册 / 象棋 / 名言的开关与间隔（与各 App 页同步） |
| 静默时段 | 最多 6 段；时段内**不做**定时刷新、App 时间表切换、RTC 醒刷；跨午夜可用 |
| App 时间表 | 最多 12 个每日到点；到点切到指定 App（天气可指定实况 / 预报） |

和风 Key 只在 **portal-go** 服务端；设备用登录后的 Token 打 `/portal/v7/...` 与 `/portal/geo/...`。
