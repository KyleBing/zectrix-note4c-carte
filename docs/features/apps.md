# App 功能说明

> 四个桌面 App 与设备 **Web 配置站** 各做什么。  
> 总览 / 按键 / 刷写见 [固件功能说明](/features/)；运行时细节见 [行为机制](/features/behavior)。  
> 版本：`{{DOC_VERSION}}`

上下短按在**已启用**的 App 间循环（顺序：**待办 → 日历 → 天气 → 相册 → 状态 → 象棋**）。顶栏色点表示当前位置（只开一个 App 时不画色点）。**BOOT 从不切 App**，只做当前页内动作。不用的 App 可在 Web `/settings` 关掉。

## 日历（CALENDAR）

本机 **PCF8563** 月历，偏「一眼看今天」。

| 项 | 说明 |
| --- | --- |
| 画面 | 顶栏年月；格内**大字公历** + **小字农历**；**今天**红底白字 |
| 周起始 | Web 设置可配周一 / 周日为第一列（默认周一） |
| 校时 | 复位后联网 NTP 校一次；平时按周期（默认约 30 天，可配）；也可在 Web 手动写 RTC / 时区 |
| 醒着 | 停在日历 App 时，本地日期跨天会自动重绘 |
| 关机 | 前台是日历 → 定时深睡，约**次日 0:00** RTC 唤醒刷新年月「今天」再睡 |
| BOOT | 立刻重绘（必要时顺带校时） |

不依赖 Portal；有 WiFi 时校时更准，纯离线也能用手设时间跑月历。

## 天气（WEATHER）

经 Portal 代理访问和风；**设备不存和风 Key**。需：天气启用 + 已登录 + 已选城市 LocationID。

| 模式 | 屏上大致内容 | BOOT |
| --- | --- | --- |
| **NOW** | 大图标 + 天气名 / 气温 / 湿度；风向与空气质量；下方未来约 6 小时气温柱 | 切到 7D |
| **7D** | 未来 7 天高低气温柱（按气温区间四色/抖动填色）；日期与周几 | 切回 NOW |

| 项 | 说明 |
| --- | --- |
| 配置 | Web `/weather`：开/关、城市搜索选点、**定时刷新**开关与间隔 |
| 醒着定时 | 开关开且停在天气 App → 按间隔自动拉数全刷 |
| 关机定时 | 前台是天气且定时开 → RTC 深睡到点醒刷再睡 |
| 失败 | 屏上错误详情 + `/errors` 日志；未配齐时提示去 `/auth`、`/weather` |

顶栏黄标标出当前是 NOW 还是 7D。柱色、风向图标等版面细节见 [行为机制 · 天气](/features/behavior#63-天气)。

## 相册（ALBUM）

墨水屏**四色照片**轮播。设备不解 JPG：在 Web `/album` 里裁切、色阶、抖动成 400×300 的 `.2bp`，再上传到 LittleFS。

| 项 | 说明 |
| --- | --- |
| 设备端 | 按「展示中」列表全屏显示；可选叠 ALBUM 顶栏与 `当前/总数` |
| BOOT | 下一张（跳过「取消展示」的） |
| 定时翻页 | Web 可开；醒着停在相册到期翻页；关机前台为相册且开关开 → RTC 到点翻页再睡 |
| 展示开关 | 「取消展示」只藏图，文件仍在，不关相册 App |
| 批量 | 导入 / 导出 ZIP、勾选删除、全选展示等 |
| 容量 | 受 LittleFS 分区限制（约数 MB 级，张数随文件变） |

电脑上也可先跑 `python3 tools/album_preview.py` 预览编辑页（不必刷机）。

## 状态（STATUS）

本机资源与定时开关一览，不依赖联网。

| 项 | 说明 |
| --- | --- |
| 内容 | 固件版本 / 编译时间、RTC 时间、Heap / PSRAM、LittleFS、电池、WiFi |
| 定时 | 天气 / 相册定时刷新是否开启及间隔；日历跨天刷新；空闲关机 |
| BOOT | 重绘当前状态 |

| 项 | 说明 |
| --- | --- |
| 画面 | 黄白格；矢量风格棋子（黑实心 / 白黄填）；左右「白方吃 / 黑方吃」 |

| 残局 | 内置约 20 局经典局面与短战术 |
| BOOT | 下一残局 |

## Web 配置

长按 **UP ~1.5s** 启动配置站（不是桌面 App 之一，但是配置它们的入口）：

1. 优先用已存 WiFi 开 **同网段站点**（墨水屏显示本机 IP）  
2. 失败则开 **AP**：SSID `Note4C-Carte`，密码 `12345678`，浏览器打开 `http://192.168.4.1`  
3. 已在 Web 时再长按 UP：**AP ↔ 同 WiFi 站点** 切换  

墨水屏配置页会画模式图标、热点名/密码或访问地址，并黄底提示「当前模式不会自动关机」。**BOOT** 退出 Web 并刷回当前可用 App。保存配置一般不自动退出。

| 路径 | 做什么 |
| --- | --- |
| `/` | 状态总览：联网、Portal、各 App 摘要、存储 / 内存 / 固件 / 电池；错误条数入口 |
| `/settings` | **App 开关**；空闲自动关机；日历周起始 / 时区 / NTP / 手动对时 |
| `/wifi` | 最多 **5** 组 SSID；选 Active；连接顺序 Active → 其余 |
| `/auth` | Portal Base URL（默认 `https://kylebing.cn/portal`）、邮箱登录、选 / 填 Diary ID |
| `/todo` | 预览当前日记正文（与墨水屏同一数据源） |
| `/weather` | 天气启用、城市搜索、定时刷新 |
| `/album` | 选图 → 裁切 / 色阶 / 抖动 → 上传；列表管理与定时翻页 |
| `/errors` | 最近错误事件（最多 40 条），可清空 |
| `/help` | 按键与 LED 图案说明（旧 `/led` 跳到这里） |

和风 Key 只在 **portal-go** 服务端；设备用登录后的 Token 打 `/portal/v7/...` 与 `/portal/geo/...`。
